Estación Meteorológica con Arduino y Pantalla OLED

Mide temperatura, humedad y presión con Arduino, BME280 y pantalla OLED I2C. Cableado seguro, librerías, código comentado, calibración y límites de una estación casera.

Arquitectura recomendada: BME280 + OLED I2C

El BME280 mide temperatura, humedad relativa y presión barométrica. Una pantalla OLED SSD1306 de 128×64 muestra los datos sin ocupar muchos pines. Ambos módulos suelen comunicarse por I2C, por lo que comparten dos líneas de datos. Confirma si tu módulo BME280 acepta 5 V: muchos breakout incluyen regulador, pero el chip desnudo trabaja a 3,3 V.

  • Arduino Uno, BME280, OLED I2C 128×64 y cables.
  • Librerías: Adafruit BME280, Adafruit Unified Sensor y Adafruit SSD1306.

Cableado I2C y diagnóstico de direcciones

En Arduino Uno, SDA es A4 y SCL es A5. Une GND de todos los módulos. Conecta VCC según la serigrafía y la hoja de datos del breakout. Las direcciones comunes son 0x76 o 0x77 para BME280 y 0x3C para OLED. Si una librería no detecta el módulo, ejecuta primero un escáner I2C: no adivines ni cambies cables con la placa energizada.

Evita una causa habitual de lecturas erróneas: no encierres el BME280 junto al regulador, pantalla o Arduino. El calor propio de la electrónica sesga la temperatura.

Sketch base para lectura y pantalla

#include <Wire.h>
#include <Adafruit_BME280.h>
#include <Adafruit_SSD1306.h>
Adafruit_BME280 bme;
Adafruit_SSD1306 display(128, 64, &Wire, -1);
void setup() {
  if (!bme.begin(0x76)) while (true); // prueba 0x77 si corresponde
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
}
void loop() {
  display.clearDisplay(); display.setTextSize(1); display.setTextColor(WHITE);
  display.setCursor(0,0);  display.print("Temp: "); display.print(bme.readTemperature(),1); display.println(" C");
  display.print("HR:   "); display.print(bme.readHumidity(),0); display.println(" %");
  display.print("Pres: "); display.print(bme.readPressure()/100.0F,1); display.println(" hPa");
  display.display(); delay(2000);
}

El chequeo de bme.begin() detiene el programa si el sensor no responde, mejor que publicar datos inexistentes. Para una aplicación final, muestra un mensaje de error y vuelve a intentar.

Interpretar presión, humedad y altitud

La presión que entrega el sensor es presión absoluta local. Para comparar con un parte meteorológico necesitas presión reducida al nivel del mar, que depende de la altitud y condiciones locales. La humedad es más confiable con circulación de aire y sin condensación. No esperes que una estación interior mida igual que una estación oficial: ubicación, abrigo y altura del sensor importan tanto como el componente.

DatoBuena práctica
TemperaturaProteger de sol directo y fuentes de calor.
HumedadUsar caja ventilada; evitar agua directa.
PresiónRegistrar tendencia, no solo un valor aislado.

Montaje exterior y siguientes mejoras

Para exterior, usa una garita ventilada y sombreada, no una caja sellada al sol. Agrega RTC para marcas de tiempo y microSD o WiFi para historial. El sensor BME280 no mide lluvia ni viento: esos instrumentos requieren sensores separados y mantenimiento mecánico.

Conclusión

El valor de este proyecto está en medir, comprobar y mejorar cada parte: cableado seguro, código legible y pruebas graduales. Empieza con el montaje mínimo, observa el resultado y añade una mejora por vez. Así podrás detectar errores sin convertir un proyecto sencillo en una caja negra.

Preguntas frecuentes

¿El BME280 mide lluvia?

No. Mide temperatura, humedad y presión. Para lluvia se necesita un pluviómetro; para viento, anemómetro y veleta.

¿Por qué el OLED queda en negro?

Revisa alimentación, GND común y la dirección I2C. OLED suele usar 0x3C, pero hay variantes.
