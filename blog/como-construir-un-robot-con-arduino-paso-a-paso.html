Cómo Construir un Robot con Arduino Paso a Paso: de Cero a Autónomo

Del chasis vacío al robot que esquiva paredes solo: selección de componentes, cableado completo, código explicado línea por línea, y las mejoras que lo convierten en un proyecto que crece contigo.

Por Alberto Gallardo, Analista Programador Computacional · 14 min de lectura

Un robot 2WD con Arduino, L298N y HC-SR04 es el proyecto que une todo lo que un principiante aprende por separado: programación, electrónica, motores y sensores, en algo que se mueve.

Componentes: qué necesitas y por qué

Este proyecto usa componentes estándar que se consiguen en cualquier tienda de electrónica o por importación, y que además se reutilizan en proyectos futuros. Si ya compraste un kit de Arduino para principiantes, probablemente ya tengas algunos de estos:

El chasis 2WD: ensamblaje y motores

Un chasis 2WD (two-wheel drive) tiene dos motores DC con ruedas en la parte trasera y una rueda loca (caster) en la parte delantera. La dirección se logra por diferencial de velocidad: ambos motores adelante = avanza recto; solo el derecho = gira a la izquierda; ambos en reversa = retrocede; uno adelante y otro atrás = gira sobre su eje.

Los kits de chasis 2WD de acrílico son los más comunes y económicos. Vienen con las plataformas precortadas, los motores con caja reductora, tornillos, separadores y la rueda loca. El ensamblaje toma unos 20-30 minutos y solo requiere un destornillador. Para ver la evolución de un robot de este tipo desde la versión más simple hasta una con múltiples sensores, este recorrido por cuatro versiones de un robot car con Arduino (en inglés) muestra cómo un mismo chasis crece con cada iteración.

Consejo de ensamblaje: atornilla el driver L298N, el Arduino y la protoboard en la plataforma superior del chasis antes de montar la plataforma sobre los motores. Es mucho más fácil acceder a los tornillos y al cableado con el chasis abierto que intentar meter un destornillador entre las dos plataformas ya montadas.

Driver L298N: conectar los motores

El L298N es el driver que traduce las señales de bajo consumo de Arduino en la corriente y el voltaje que los motores necesitan para girar. Lo cubrimos en detalle en Control de Motores DC con Arduino y L298N, pero aquí va el resumen de conexión para el robot:

  • Motor izquierdo → OUT1 y OUT2 del L298N.
  • Motor derecho → OUT3 y OUT4 del L298N.
  • IN1, IN2 → pines digitales de Arduino (dirección del motor izquierdo).
  • IN3, IN4 → pines digitales de Arduino (dirección del motor derecho).
  • ENA, ENB → pines PWM (~) de Arduino (velocidad de cada motor). Retira los jumpers de ENA/ENB para habilitar control de velocidad por software.
  • 12V del L298N → positivo de la batería; GND → negativo de la batería Y GND de Arduino.
El GND de la batería debe estar conectado también al GND de Arduino. Es el error de cableado más frecuente en el primer robot: sin tierra común, las señales de control no tienen referencia válida y los motores no responden o responden de forma errática.

Sensor HC-SR04: medir la distancia

El HC-SR04 emite un pulso ultrasónico, espera el eco, y la duración del eco indica la distancia al objeto frente al sensor. Lo cubrimos en detalle en Sensor Ultrasónico HC-SR04: Medición de Distancias. Para una demostración práctica de cómo el HC-SR04 controla LEDs según la proximidad, este tutorial de alerta de proximidad con HC-SR04 y LEDs (en inglés) es un buen ejercicio previo a montarlo en el robot.

En el robot, el sensor se monta al frente, apuntando hacia adelante. Las conexiones: VCC → 5V de Arduino, GND → GND, TRIG → un pin digital, ECHO → otro pin digital. Si montas el sensor sobre un servo SG90, el robot puede "mirar" a la izquierda y a la derecha antes de decidir hacia dónde girar cuando detecta un obstáculo al frente.

// Función para medir distancia con HC-SR04
long medirDistancia(int pinTrig, int pinEcho) {
  digitalWrite(pinTrig, LOW);
  delayMicroseconds(2);
  digitalWrite(pinTrig, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinTrig, LOW);
  long duracion = pulseIn(pinEcho, HIGH, 25000); // timeout 25ms ≈ 4m
  if (duracion == 0) return 999; // sin eco = sin obstáculo cercano
  return duracion * 0.034 / 2;  // distancia en cm
}

Código completo: evasión de obstáculos

La lógica de navegación autónoma más simple y efectiva para un primer robot:

  1. Avanza recto.
  2. Mide la distancia al frente continuamente.
  3. Si la distancia es menor a 25 cm → detente, retrocede un poco, mide a la derecha y a la izquierda (con el servo si lo tienes), y gira hacia el lado con más espacio.
  4. Repite.
// Robot evasor de obstáculos - Arduino + L298N + HC-SR04
#include <Servo.h>

// Pines del motor (L298N)
const int IN1 = 7, IN2 = 8;    // Motor izquierdo
const int IN3 = 12, IN4 = 13;  // Motor derecho
const int ENA = 5, ENB = 6;    // PWM velocidad

// Pines del HC-SR04
const int TRIG = 3, ECHO = 4;

// Servo para girar el sensor
Servo servoSensor;
const int PIN_SERVO = 9;

const int VEL = 180;           // Velocidad PWM (0-255)
const int DIST_MIN = 25;       // Distancia mínima en cm

void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
  pinMode(ENA, OUTPUT); pinMode(ENB, OUTPUT);
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  servoSensor.attach(PIN_SERVO);
  servoSensor.write(90); // Sensor al frente
  delay(500);
}

long medirDistancia() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long dur = pulseIn(ECHO, HIGH, 25000);
  return dur == 0 ? 999 : dur * 0.034 / 2;
}

void avanzar()   { digitalWrite(IN1,HIGH); digitalWrite(IN2,LOW);
                   digitalWrite(IN3,HIGH); digitalWrite(IN4,LOW);
                   analogWrite(ENA,VEL);   analogWrite(ENB,VEL); }
void retroceder(){ digitalWrite(IN1,LOW);  digitalWrite(IN2,HIGH);
                   digitalWrite(IN3,LOW);  digitalWrite(IN4,HIGH);
                   analogWrite(ENA,VEL);   analogWrite(ENB,VEL); }
void girarDer()  { digitalWrite(IN1,HIGH); digitalWrite(IN2,LOW);
                   digitalWrite(IN3,LOW);  digitalWrite(IN4,HIGH);
                   analogWrite(ENA,VEL);   analogWrite(ENB,VEL); }
void girarIzq()  { digitalWrite(IN1,LOW);  digitalWrite(IN2,HIGH);
                   digitalWrite(IN3,HIGH); digitalWrite(IN4,LOW);
                   analogWrite(ENA,VEL);   analogWrite(ENB,VEL); }
void detener()   { analogWrite(ENA,0);     analogWrite(ENB,0); }

void loop() {
  long distFrente = medirDistancia();

  if (distFrente > DIST_MIN) {
    avanzar();
  } else {
    detener(); delay(200);
    retroceder(); delay(400);
    detener(); delay(200);

    // Mirar a la derecha
    servoSensor.write(30); delay(400);
    long distDer = medirDistancia();

    // Mirar a la izquierda
    servoSensor.write(150); delay(400);
    long distIzq = medirDistancia();

    // Volver al frente
    servoSensor.write(90); delay(200);

    // Girar hacia el lado con más espacio
    if (distDer > distIzq) {
      girarDer(); delay(500);
    } else {
      girarIzq(); delay(500);
    }
    detener(); delay(100);
  }
  delay(50);
}

Este código es un punto de partida funcional, no un destino. Una vez que el robot se mueve y esquiva paredes, las mejoras naturales son: ajustar DIST_MIN para reaccionar más lejos o más cerca, cambiar VEL para ir más rápido o más lento, y agregar más sensores para cubrir los flancos.

Alimentación: cómo no quemar nada

La regla de oro: nunca alimentes los motores desde el pin de 5V de Arduino. Los motores se alimentan desde la batería a través del L298N; el Arduino se alimenta por USB durante la programación y, una vez desconectado del computador, desde el pin VIN con la misma batería o con un regulador separado.

Opciones de batería razonables para este robot:

  • 4 pilas AA: la opción más simple y accesible. 6V nominales, suficiente para los motores y para alimentar el Arduino vía el regulador del L298N. Autonomía limitada (30-60 minutos de movimiento continuo).
  • Pack LiPo 7,4V (2S): más liviano, más potencia, recargable. Requiere cuidado con la descarga; revisa nuestra guía de Módulo de Carga TP4056 para carga segura.

Para elegir el cable y la sección adecuados entre la batería, el L298N y los motores, revisa Qué Cable y Conector Usar Según la Corriente.

Hoja de ruta de mejoras progresivas

Lo mejor de este proyecto es que crece contigo. Cada mejora enseña un concepto nuevo:

  • Seguidor de línea: agrega sensores infrarrojos bajo el chasis para seguir una línea negra. Revisa nuestra guía de Sensores Infrarrojos para Robots Siguelíneas.
  • Control por Bluetooth: agrega un módulo HC-05 o usa un ESP32 con BLE para controlarlo desde el celular.
  • Encoders de rueda: mide cuánto avanza realmente cada rueda para hacer giros precisos de 90° exactos. Revisa Encoders para Motores DC.
  • Control PID: una vez con encoders, implementa un controlador PID para que ambas ruedas giren a la misma velocidad y el robot avance realmente recto. Lo cubrimos en Control PID con Arduino.
  • Visión y navegación: reemplaza el Arduino por una Raspberry Pi, agrega una cámara, y entra en el mundo de la navegación autónoma con visión. La evolución desde un robot simple hasta uno con percepción completa se puede explorar también en este análisis de la evolución de un robot car en cuatro versiones (en inglés).

Preguntas frecuentes

¿Puedo construir este robot sin saber programar?

El código de este artículo está completo y comentado: puedes copiarlo y cargarlo en tu Arduino tal cual, y el robot se moverá y esquivará obstáculos. No necesitas escribir código desde cero. Lo que sí necesitas es tener el IDE de Arduino instalado y saber cómo subir un sketch a la placa, algo que cubrimos en Primeros Pasos con Arduino. Entender qué hace cada línea es el siguiente paso, y viene naturalmente al modificar los valores y ver cómo cambia el comportamiento.

¿Cuánto cuesta construir este robot?

Con componentes importados de AliExpress o tiendas de electrónica online, el costo total ronda los US$ 25-50: chasis 2WD con motores ($8-15), Arduino Uno compatible ($4-8), L298N ($3-5), HC-SR04 ($2-3), servo SG90 ($2-3), pilas o pack de baterías ($5-10), y cables ($2-3). En tiendas locales en Chile los precios pueden ser el doble, pero sigue siendo uno de los proyectos de robótica más accesibles que existen.

¿Por qué mi robot gira en círculos en vez de ir recto?

Las dos causas más comunes: motores con velocidad distinta de fábrica (se soluciona ajustando el valor de PWM de cada motor individualmente hasta que ambas ruedas giren a la misma velocidad), o una rueda loca que no gira libremente y genera fricción desigual (se soluciona lubricando el eje o reemplazándola por una de mejor calidad). Encoders con control PID es la solución definitiva.

¿Puedo usar un ESP32 en vez de Arduino para este robot?

Sí, y ganarias WiFi y Bluetooth integrados, lo que permite controlarlo desde el celular sin hardware adicional. El código necesita adaptaciones menores (los pines PWM se configuran distinto en ESP32) pero la lógica es la misma. Si planeas agregar visión o IoT al robot más adelante, el ESP32 es una mejor base que el Arduino Uno desde el inicio.

¿Este robot puede funcionar sobre alfombra?

Sobre alfombra de pelo corto sí, aunque más lento que en piso duro. Sobre alfombra de pelo largo, las ruedas pueden patinar y la rueda loca puede atascarse. Si tu superficie principal es alfombra, un chasis 4WD con neumáticos de goma da mucha mejor tracción que un 2WD con rueda loca, a cambio de más consumo y más peso.
