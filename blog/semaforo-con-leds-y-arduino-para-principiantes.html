Semáforo con LEDs y Arduino para Principiantes

Construye un semáforo con Arduino Uno, LEDs y resistencias. Incluye diagrama de conexiones, código comentado, cálculo de resistencia, secuencia segura y mejoras con pulsador.

Materiales y por qué cada LED necesita resistencia

  • Arduino Uno o compatible, protoboard y cables.
  • Un LED rojo, amarillo y verde.
  • Tres resistencias de 220 Ω a 330 Ω.

Un LED no limita por sí solo la corriente. Con USB de 5 V, un LED rojo cercano a 2 V y una resistencia de 220 Ω, la estimación es (5 − 2) / 220 = 13,6 mA, un valor seguro. La pata larga es el ánodo; la corta y el lado plano corresponden al cátodo.

Conexiones paso a paso

Conecta el ánodo de cada LED a D8 (rojo), D9 (amarillo) y D10 (verde). Desde cada cátodo lleva una resistencia a GND; la resistencia puede ir en el ánodo en vez del cátodo, pero debe estar en serie. Todas las tierras son comunes.

Antes de energizar: revisa que cada resistencia esté en la misma fila del LED correspondiente y que ningún cable una directamente 5V con GND.

Código del semáforo con transición amarilla

const byte ROJO = 8, AMARILLO = 9, VERDE = 10;

void apagarTodo() {
  digitalWrite(ROJO, LOW); digitalWrite(AMARILLO, LOW);
  digitalWrite(VERDE, LOW);
}
void setup() {
  pinMode(ROJO, OUTPUT); pinMode(AMARILLO, OUTPUT); pinMode(VERDE, OUTPUT);
}
void loop() {
  apagarTodo(); digitalWrite(VERDE, HIGH);    delay(5000);
  apagarTodo(); digitalWrite(AMARILLO, HIGH); delay(1500);
  apagarTodo(); digitalWrite(ROJO, HIGH);     delay(5000);
}

La función apagarTodo() evita estados residuales y deja explícito que solo una luz debe quedar encendida. Para una maqueta de dos sentidos, nunca programes ambos verdes simultáneamente: incluye un intervalo de todo rojo antes de habilitar el otro sentido.

Diseña una secuencia que no genere conflictos

FaseDuración inicialObjetivo
Verde5 sPermitir paso.
Amarillo1,5 sAdvertir cambio; no acelerar la marcha.
Rojo5 sDetener el sentido controlado.
Todo rojo (dos sentidos)0,5–1 sSeparar fases y reducir conflicto.

Estos tiempos son didácticos, no parámetros para infraestructura real. Un semáforo de calle exige normativa, detección certificada, redundancia y controladores homologados.

Mejoras: botón peatonal y código sin delay

Agrega un pulsador entre D2 y GND y configura pinMode(2, INPUT_PULLUP); al leer LOW, registra una solicitud peatonal y atiéndela al terminar la fase verde. En proyectos que además lean sensores, reemplaza delay() por una máquina de estados con millis(): así la placa puede medir entradas mientras cronometra las luces.

Uso responsable: este montaje es una maqueta educativa. No conectes Arduino a semáforos reales ni a circuitos de red eléctrica.

Conclusión

El valor de este proyecto está en medir, comprobar y mejorar cada parte: cableado seguro, código legible y pruebas graduales. Empieza con el montaje mínimo, observa el resultado y añade una mejora por vez. Así podrás detectar errores sin convertir un proyecto sencillo en una caja negra.

Preguntas frecuentes

¿Puedo conectar varios LEDs a un solo pin?

No es recomendable para este proyecto. Cada LED necesita su propia resistencia y un pin permite controlar cada color de forma independiente.

¿Por qué se quema mi LED?

Casi siempre falta la resistencia limitadora o está conectada en paralelo. Desconecta la alimentación y revisa el montaje.
