Radar con Sensor Ultrasónico y Processing

Crea un radar didáctico con Arduino, HC-SR04, servo y Processing. Aprende conexiones, temporización, protocolo serie y límites físicos de la medición ultrasónica.

Qué construye realmente este proyecto

Un servo mueve el sensor HC-SR04 en un barrido angular. Arduino mide el tiempo de eco y envía ángulo y distancia por serie. Processing dibuja esa información en un computador. Es una visualización de obstáculos, no un radar electromagnético: el sensor emite ultrasonido y necesita un objeto que refleje el sonido.

  • Arduino Uno, HC-SR04, microservo SG90 y fuente USB estable.
  • Procesing instalado en el computador y cable USB de datos.

Conexiones y alimentación del servo

Conecta TRIG a D10, ECHO a D11 y el servo a D9; todos comparten GND. El HC-SR04 se alimenta a 5 V en un Uno. Un servo puede causar reinicios al arrancar porque demanda picos de corriente: si ocurre, usa una fuente externa regulada de 5 V para el servo y une únicamente las tierras. No alimentes motores grandes desde el pin 5V del Arduino.

Sketch: medir, limitar y enviar un protocolo estable

#include <Servo.h>
Servo radar; const byte TRIG=10, ECHO=11;
float distanciaCM(){
  digitalWrite(TRIG,LOW); delayMicroseconds(2);
  digitalWrite(TRIG,HIGH); delayMicroseconds(10); digitalWrite(TRIG,LOW);
  unsigned long t=pulseIn(ECHO,HIGH,30000); // timeout: evita bloqueo
  return t ? t*0.0343/2.0 : -1;
}
void setup(){ radar.attach(9); pinMode(TRIG,OUTPUT); pinMode(ECHO,INPUT); Serial.begin(115200); }
void loop(){
 for(int a=15;a<=165;a+=2){ radar.write(a); delay(35); Serial.print(a);Serial.print(',');Serial.println(distanciaCM()); }
 for(int a=165;a>=15;a-=2){ radar.write(a); delay(35); Serial.print(a);Serial.print(',');Serial.println(distanciaCM()); }
}

El formato angulo,distancia es fácil de leer en Processing. El timeout de 30 ms evita quedar detenido si no existe eco; una medición inválida se envía como −1.

Lectura en Processing: separa interfaz y hardware

En Processing importa processing.serial.*, abre el puerto correcto a 115200 y procesa líneas completas con readStringUntil(' '). Divide con split(trim(linea), ','), valida que existan dos campos y conviértelos con int() y float(). Dibuja el arco con el ángulo y una marca radial proporcional a la distancia. Validar antes de dibujar evita que una línea incompleta rompa la interfaz.

Rango, errores y seguridad

El rango práctico del HC-SR04 depende del material, ángulo y ruido; superficies blandas o inclinadas reflejan poco sonido. No interpretes una sola lectura como verdad: promedia varias muestras o aplica una mediana. Mantén el barrido entre 15° y 165° para no forzar el servo contra su tope. Este montaje no es adecuado para navegación autónoma ni sistemas de seguridad.

Conclusión

El valor de este proyecto está en medir, comprobar y mejorar cada parte: cableado seguro, código legible y pruebas graduales. Empieza con el montaje mínimo, observa el resultado y añade una mejora por vez. Así podrás detectar errores sin convertir un proyecto sencillo en una caja negra.

Preguntas frecuentes

¿Por qué marca cero o distancias erráticas?

Revisa GND común, cables TRIG/ECHO y la alimentación del servo. Un objeto inclinado o blando puede no devolver eco.

¿Processing no recibe datos?

Comprueba puerto y 115200 baudios; cierra el Monitor Serie porque solo un programa puede abrir el puerto a la vez.
