Primeros Pasos con Arduino Uno: de Cero a tu Primer Sketch

Instala Arduino IDE, conoce los pines del Arduino Uno y carga tu primer sketch Blink. Guía paso a paso con selección de placa, puerto, errores frecuentes y buenas prácticas.

Qué necesitas y cómo reconocer la placa

Arduino Uno es una placa basada en el microcontrolador ATmega328P. Para empezar necesitas la placa, un cable USB de datos (muchos cables de carga no transmiten datos) y un computador. La versión R3 usa lógica de 5 V: sus pines de entrada y salida no son tolerantes a 12 V. Alimenta la placa por USB mientras aprendes; no unas fuentes externas al pin 5V sin conocer su tensión y polaridad.

Regla de banco: desconecta USB antes de cambiar cables. Nunca conectes un LED directamente entre 5 V y GND: usa una resistencia en serie para limitar corriente.

Instala Arduino IDE y selecciona placa y puerto

Descarga Arduino IDE desde el sitio oficial. Conecta el Uno, abre Herramientas → Placa → Arduino AVR Boards → Arduino Uno y luego Herramientas → Puerto; elige el puerto que apareció al conectar la placa. Si no aparece, prueba otro cable y revisa el administrador de dispositivos. En clones con conversor CH340 puede ser necesario instalar su controlador desde el proveedor.

Un sketch tiene dos funciones obligatorias: setup(), que se ejecuta una vez, y loop(), que se repite. Compilar verifica el programa; cargar además lo transfiere por USB.

Tu primer sketch: Blink, explicado línea por línea

El LED integrado de la mayoría de los Uno está conectado al pin digital 13. Carga este programa sin montar ningún circuito:

const byte LED = LED_BUILTIN;

void setup() {
  pinMode(LED, OUTPUT);     // D13 será una salida
}

void loop() {
  digitalWrite(LED, HIGH);  // entrega nivel alto
  delay(1000);              // espera 1 000 ms
  digitalWrite(LED, LOW);   // entrega nivel bajo
  delay(1000);
}

Haz clic en Verificar y luego en Subir. El LED marcado como L debe parpadear cada segundo. Cambia ambos valores de delay() a 200 para comprobar que entiendes la relación entre milisegundos y velocidad.

Pines, corriente y lectura del código

D0 y D1Serie USBNo los uses al cargar sketches.
D2–D13Entradas/salidas digitalesMáximo recomendado 20 mA por pin.
A0–A5Lectura analógica; también digitalesLa lectura por defecto es 0–5 V.

Abre Herramientas → Monitor serie a la misma velocidad que declares en Serial.begin(). Es la herramienta más útil para ver valores de sensores y diagnosticar tu programa.

Errores frecuentes y cómo resolverlos

  • “avrdude: ser_open”: puerto equivocado, cable solo de carga o monitor serie abierto.
  • “not in sync”: confirma Arduino Uno y puerto; cierra programas que usen el puerto.
  • LED no parpadea: vuelve a cargar el sketch y revisa que uses LED_BUILTIN, no un número supuesto.
  • La placa se reinicia: desconecta el circuito externo: suele haber cortocircuito o consumo excesivo.
Seguridad: Arduino no es una fuente de potencia. Motores, relés y tiras LED requieren fuente y etapa de control adecuadas; comparte GND cuando corresponda, pero no los alimentes desde un pin.

Conclusión

El valor de este proyecto está en medir, comprobar y mejorar cada parte: cableado seguro, código legible y pruebas graduales. Empieza con el montaje mínimo, observa el resultado y añade una mejora por vez. Así podrás detectar errores sin convertir un proyecto sencillo en una caja negra.

Preguntas frecuentes

¿Por qué no aparece mi Arduino Uno en el IDE?

Comprueba primero que el cable sea de datos, prueba otro puerto USB y selecciona la placa y el puerto correctos. Los clones CH340 pueden necesitar su controlador.

¿Qué hace setup y qué hace loop?

setup se ejecuta una sola vez al encender o reiniciar. loop se ejecuta repetidamente mientras la placa tenga alimentación.
