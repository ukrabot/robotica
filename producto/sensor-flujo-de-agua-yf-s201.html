¿Qué es el sensor de flujo de agua YF-S201?

El YF-S201 es un caudalímetro compacto de turbina para tubería de 1/2 pulgada. El agua hace girar un rotor interno con un imán; un sensor de efecto Hall detecta cada vuelta y entrega un tren de pulsos. El controlador cuenta esos pulsos para estimar caudal instantáneo en litros por minuto y volumen acumulado en litros.

A diferencia de un presostato, el YF-S201 no mide presión. Tampoco entrega litros directamente: su salida es una frecuencia que debe convertirse mediante un factor K y calibrarse en la instalación real. Es útil en riego, dosificación no crítica, llenado de depósitos y monitoreo doméstico donde se busca una solución económica.

La pieza móvil introduce una pequeña pérdida de carga y requiere agua relativamente limpia. Sedimentos, sarro, burbujas, viscosidad y una instalación con turbulencia cambian la lectura; por eso no conviene tratar el valor nominal como una medición certificada.

Decisión rápida: elígelo si necesitas detectar paso de agua y obtener una estimación de 1 a 30 L/min. Para facturación, agua potable certificada, químicos, hidrocarburos o procesos críticos necesitas un medidor homologado para ese servicio.

Cables del sensor

La codificación más común es rojo = VCC, negro = GND y amarillo = señal. No dependas solo del color: revisa la etiqueta o documentación del lote antes de energizar. Invierte polaridad y puedes dañar la electrónica Hall.

La presión máxima no es una presión de trabajo recomendada. Diseña con margen, considera la temperatura y evita golpes de ariete. Roscas, adaptadores, mangueras y sellos suelen limitar el conjunto antes que el cuerpo del sensor.

Cómo convertir pulsos a litros y calibrar

La relación nominal más citada es frecuencia_Hz = 7,5 × caudal_L/min. De ella se obtienen unos 450 pulsos por litro. Así, a 10 L/min la salida debería rondar 75 Hz. Para volumen acumulado se divide el número de pulsos por el factor calibrado:

litros = pulsos / pulsos_por_litro

caudal_Lmin = pulsos × 60000 / (pulsos_por_litro × intervalo_ms)

El valor 450 sirve para comenzar, no para cerrar una calibración. La geometría de la tubería, presión, orientación, tolerancia del rotor y el propio líquido cambian el factor. Para mejorar el resultado:

  1. Instala el sensor en su posición definitiva. Calibrar sobre la mesa y luego cambiar tuberías invalida parte del ajuste.
  2. Haz pasar un volumen conocido. Usa, por ejemplo, un recipiente graduado confiable de 5 o 10 litros.
  3. Cuenta todos los pulsos. Utiliza interrupciones y evita imprimir desde la rutina ISR.
  4. Calcula el factor. Divide los pulsos contados por los litros reales.
  5. Repite a varios caudales. Comprueba bajo, medio y alto; promedia ensayos estables.
  6. Guarda el factor calibrado. Documenta fecha, montaje, líquido y temperatura aproximada.

Si cuentas 4.620 pulsos al llenar exactamente 10 litros, tu factor será 462 pulsos/L, no 450. Usar ese número reduce el error sistemático en ese montaje.

Instalación hidráulica y eléctrica

  1. Limpia la línea. Retira virutas y suciedad; instala un filtro aguas arriba si hay sedimentos.
  2. Respeta la flecha de flujo. El cuerpo indica la dirección. Montarlo al revés altera o impide la medición.
  3. Evita turbulencia inmediata. Como punto de partida, deja tramos rectos antes y después; válvulas y codos pegados al sensor empeoran la repetibilidad.
  4. Sella sin obstruir. Usa el sellador correcto para la rosca y el fluido. No permitas que cinta o pasta invada el paso interno.
  5. No cargues el cuerpo. Alinea y sujeta la tubería para que el plástico no reciba torsión mecánica.
  6. Cablea con la energía cortada. Confirma VCC, GND y señal; protege la entrada de 3,3 V cuando corresponda.
  7. Purga el aire y revisa fugas. Las burbujas afectan el rotor y una fuga invalida la lectura.
  8. Calibra y fija alarmas razonables. Filtra el caudal y exige varias muestras antes de declarar una falla.

No es un componente de seguridad. Una electroválvula debe tener cierre seguro, protección contra desbordamiento y supervisión independiente si una fuga puede causar daños.

Código de prueba con Arduino

Este ejemplo cuenta pulsos en D2, calcula caudal cada segundo y acumula volumen. Mantiene la rutina de interrupción mínima para no perder eventos.

const byte PIN_FLUJO = 2;
const float PULSOS_POR_LITRO = 450.0; // reemplazar tras calibrar
volatile unsigned long pulsos = 0;
unsigned long tAnterior = 0;
float litrosTotales = 0.0;

void contarPulso() {
  pulsos++;
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_FLUJO, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(PIN_FLUJO), contarPulso, FALLING);
  tAnterior = millis();
}

void loop() {
  unsigned long ahora = millis();
  unsigned long dt = ahora - tAnterior;
  if (dt >= 1000) {
    noInterrupts();
    unsigned long n = pulsos;
    pulsos = 0;
    interrupts();

    float caudal = n * 60000.0 / (PULSOS_POR_LITRO * dt);
    litrosTotales += n / PULSOS_POR_LITRO;
    Serial.print("Caudal: "); Serial.print(caudal, 2);
    Serial.print(" L/min | Total: "); Serial.print(litrosTotales, 3);
    Serial.println(" L");
    tAnterior = ahora;
  }
}

Si la cuenta permanece en cero, comprueba flecha, alimentación, tierra común y nivel de la señal. Si el valor es inestable, separa el cable de motores y relés, agrega desacoplo, revisa conectores y calcula una media o mediana sin ocultar fallas reales.
