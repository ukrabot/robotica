¿Qué es el sensor de sonido KY-038?

El KY-038 es un módulo de detección acústica con micrófono electret, comparador LM393 y potenciómetro de ajuste. Ofrece una salida analógica AO asociada a la señal del micrófono y una salida digital DO que cambia cuando el nivel supera el umbral configurado.

Está pensado para reconocer eventos sonoros: una palmada, golpe, timbre, alarma o aumento de ruido. No es un sonómetro calibrado, no entrega decibeles y no identifica palabras por sí solo. Tampoco reemplaza una interfaz de audio si necesitas grabar voz o analizar frecuencias con fidelidad.

Su mayor ventaja es la sencillez. Con DO puedes disparar una acción sin procesar audio; con AO puedes observar cambios relativos de intensidad desde el ADC del microcontrolador. La sensibilidad real depende de distancia, orientación, ruido ambiente, alimentación y tolerancias del módulo.

Compra informada: el KY-038 es adecuado para detección cualitativa de sonido. Si tu requisito dice “65 dB”, “respuesta entre 20 Hz y 20 kHz” o “reconocimiento de voz”, necesitas un micrófono y una cadena de medición con especificaciones conocidas.

No existe una conversión universal de analogRead() a dB. Faltan una referencia acústica, ganancia conocida, curva de frecuencia y calibración. Presenta AO como nivel relativo, no como medición certificada.

AO vs DO: qué salida usar

SalidaQué entregaAplicación recomendada
AO (analógica)Variación de tensión del circuito de micrófonoComparar intensidad relativa, graficar picos o procesar por software.
DO (digital)HIGH/LOW según comparador LM393Detectar palmada, golpe o alarma sobre un umbral.

El potenciómetro azul ajusta la referencia del comparador, de modo que afecta a DO. Gíralo en pasos pequeños mientras observas el LED de estado. El sentido “más sensible” no es idéntico en todas las versiones, así que se calibra por comportamiento y no por una regla fija.

AO contiene una componente de reposo y ruido. Para estimar actividad sonora es más útil muestrear durante una ventana corta y calcular máximo - mínimo que leer una sola muestra. Aun así, el ancho de banda y la ganancia del módulo no están definidos para audio de calidad.

Raspberry Pi3,3 VDO directo; AO requiere ADC externo como MCP3008.

En ESP32 y Raspberry Pi evita señales de 5 V. Alimentar el módulo a 3,3 V ayuda a mantener AO/DO en un rango compatible; si tu variante exige 5 V, adapta niveles y comprueba con multímetro.

La Raspberry Pi no tiene ADC integrado: puede leer DO como un evento digital, pero para AO necesita un convertidor analógico-digital externo. En ESP32 suele convenir ADC1 si Wi‑Fi está activo, ya que varios pines ADC2 presentan restricciones según el chip y el framework.

Cómo saber si el KY-038 es el sensor correcto

Elígelo para

  • Encender una luz o activar una secuencia al detectar una palmada.
  • Detectar golpes, timbres o alarmas en un prototipo educativo.
  • Crear un indicador relativo de ruido con LEDs.
  • Aprender comparadores, umbrales, ADC e histéresis por software.

No es la mejor opción para

  • Medir decibeles: utiliza un sonómetro calibrado o una cadena de micrófono caracterizada.
  • Grabar voz: usa micrófono I²S, preamplificador de audio o interfaz USB.
  • Reconocer comandos: requiere captura adecuada y procesamiento adicional.
  • Separar un sonido específico en ambiente ruidoso: necesitas filtrado espectral o aprendizaje automático.
  • Alarmas de seguridad certificadas: el módulo hobby no ofrece diagnóstico ni homologación.

Conexión, ajuste y prueba de detección

  1. Verifica la serigrafía. Identifica +/VCC, G/GND, AO y DO; el orden físico puede cambiar entre módulos.
  2. Alimenta con la placa apagada. Usa 5 V para Arduino de 5 V o 3,3 V para ESP32, y comparte GND.
  3. Conecta ambas salidas. Lleva AO a una entrada analógica y DO a una digital para observarlas a la vez.
  4. Parte con sensibilidad moderada. Gira el trimpot lentamente hasta que el LED deje de dispararse con el ruido de fondo.
  5. Genera el evento real. Prueba la palmada o alarma a la distancia de uso, no pegada al micrófono.
  6. Agrega antirrebote temporal. Una palmada produce múltiples oscilaciones; aplica 100–300 ms de bloqueo si quieres un solo evento.
  7. Repite en condiciones reales. Ventiladores, motores, cajas y paredes cambian la respuesta acústica.

Evita montar el micrófono junto a relés, reguladores conmutados o motores. Usa cables cortos, desacoplo de alimentación y separación mecánica de vibraciones. Si DO oscila justo en el umbral, aplica histéresis o confirmación temporal en software.

Código de ejemplo para Arduino

El siguiente sketch informa el estado digital y calcula la amplitud pico a pico relativa de AO durante una ventana de 50 ms. El resultado sigue siendo una escala ADC, no decibeles.

const byte PIN_AO = A0;
const byte PIN_DO = 2;

void setup() {
  Serial.begin(115200);
  pinMode(PIN_DO, INPUT);
}

void loop() {
  int minimo = 1023;
  int maximo = 0;
  unsigned long inicio = millis();

  while (millis() - inicio < 50) {
    int muestra = analogRead(PIN_AO);
    if (muestra < minimo) minimo = muestra;
    if (muestra > maximo) maximo = muestra;
  }

  int amplitud = maximo - minimo;
  int estadoDO = digitalRead(PIN_DO);
  Serial.print("Amplitud relativa: "); Serial.print(amplitud);
  Serial.print(" | DO: "); Serial.println(estadoDO);
}

Interpretación: observa qué valor de DO coincide con el LED durante un sonido; algunas variantes disparan en LOW y otras invierten la indicación. Define el software después de esa prueba.

¿El KY-038 mide decibeles?

No. AO entrega un nivel relativo sin calibración acústica. No existe una fórmula universal para convertir su lectura ADC a dB.

¿Qué diferencia hay entre AO y DO?

AO es una salida analógica relacionada con la señal del micrófono. DO es la salida binaria del comparador y cambia al superar el umbral ajustado con el potenciómetro.

¿Funciona con Arduino Uno?

Sí. Conecta VCC a 5 V, GND a GND, AO a una entrada analógica y DO a un pin digital, verificando siempre la serigrafía.

¿Puedo conectarlo al ESP32?

Sí. Se recomienda alimentarlo a 3,3 V para mantener las salidas dentro del rango del ESP32. No apliques 5 V a sus GPIO o ADC.

¿Sirve para reconocer voz?

No por sí solo. Puede detectar que hubo sonido, pero reconocer palabras requiere captura de audio con mejor calidad y un algoritmo de procesamiento.
